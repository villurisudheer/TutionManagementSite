# V5.2 Theme Guide — Academy Pop

## Default light mode

- Canvas/background: `#E6E0D1`
- Primary accent: red `#C8202F`
- Secondary accent: blue `#1F5FBF`
- Warm cream panels and cards are used so the interface remains readable while keeping the requested off-white base visible.

## Default dark mode

- Canvas/background: true black `#000000`
- Primary accent: navy blue `#153A6B`
- Secondary accent: maroon `#7B1E35`
- Panels remain near-black/navy so cards are distinguishable from the true-black page.

## Customization

In **Settings & Excel → Appearance & Theme**, V5.2 lets each browser/device independently change:

- Theme: Follow device / Light / Dark
- Light primary colour
- Light secondary colour
- Dark primary colour
- Dark secondary colour
- Background image darkness
- Corner style
- Contrast
- Device layout
- Information density
- Text size
- Motion

The four accent colours are saved locally per device and do not alter tuition data or the database.

## Colour-pop treatment

V5.2 uses the primary/secondary pair on active navigation, dashboard card borders and values, primary actions, table headers, badges, section markers, focus rings and subtle hover states. The aim is a more energetic education-management interface without sacrificing readability.
