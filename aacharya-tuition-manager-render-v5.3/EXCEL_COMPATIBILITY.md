# Excel / Google Sheets Compatibility — V5.3

Use the workbook generated by V5.3: `Aacharya_Tuition_Master_v5_3.xlsx`.

If an older `Aacharya_Tuition_Master_v5.xlsx` is still on the Render disk, do not use it as the compatibility test. Log in to the admin page and click **Rebuild V5.3 Workbook**, then download the new V5.3 file.

The app keeps all live tuition data in SQLite; the XLSX file is a generated reporting copy. Upgrading the workbook writer does not require deleting or migrating the SQLite database.
