# Render Setup — Parent Portal Extension 1.0

## 1. Deploy the patched main manager first

Use the supplied **Aacharya Tuition Manager v3 Parent Bridge** project.

In the main-manager Render service add:

```text
PARENT_PORTAL_URL=https://YOUR-PARENT-PORTAL.onrender.com
PARENT_PORTAL_SECRET=YOUR_LONG_RANDOM_SHARED_SECRET
```

You can set `PARENT_PORTAL_URL` after the extension receives its Render URL.

## 2. Deploy this extension

Put this extension folder at the root of a separate GitHub repository.

Create a Render Blueprint from `render.yaml` or create a Node Web Service.

Set:

```text
EXTENSION_ADMIN_EMAIL=your-private-email
EXTENSION_ADMIN_PASSWORD=your-strong-private-password
MAIN_MANAGER_URL=https://YOUR-MAIN-MANAGER.onrender.com
PARENT_PORTAL_SECRET=THE_SAME_SHARED_SECRET_USED_IN_MAIN
PUBLIC_BASE_URL=https://YOUR-PARENT-PORTAL.onrender.com
```

`EXTENSION_SESSION_SECRET` can be generated by Render.

## 3. Persistent disk

The included `render.yaml` requests a 1 GB disk mounted at:

```text
/var/data
```

This is where the extension stores:

- `parent_portal.sqlite`
- `payment-proofs/`

Use persistent storage for real parent/payment information.

## 4. Test the connection

Open:

```text
https://YOUR-PARENT-PORTAL.onrender.com/extension-admin
```

Login, then go to **Integration** and click **Test Integration**.

It should report that the main tuition manager is connected.

## 5. Admission test

1. Submit one student through the main public admission form.
2. Accept that admission in the main tuition manager.
3. Open the extension admin.
4. Go to **Students & Invites**.
5. If the student is missing, click **Sync Accepted Admissions**.
6. Click **Generate / Replace Invite** and copy the invite URL.
7. Open the invite URL in a private/incognito browser and create a parent account.

## 6. Add the course end date

In **Extension Admin → Enrollments**, create an enrollment for the child.

The extension cannot safely guess the course end date. The end date controls warning/grace/account closure.

## 7. Payment-proof test

From the parent portal:

1. Open **Fees & Payment Proof**.
2. Record a payment.
3. Upload the compulsory screenshot/receipt.
4. Submit.

From extension admin:

1. Open **Payment Proofs**.
2. View the screenshot.
3. Click **Approve & Record in Main**.

Then open the main tuition manager Payments section and its Excel export. The verified payment should be present.
