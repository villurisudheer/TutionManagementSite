# Integrated Chemistry Practice Lab

This folder is a module of the main academy service. Open `/chemistry` after signing into any academy portal. Do not deploy the original standalone server. The main `v7/chemistry.js` provides authorization and durable progress.

Original question bank and scoring core are preserved. Run question/DOM QA with Node 24 and a development installation of jsdom, or set JSDOM_MODULE to its absolute module path. See ../COMBINED_FEATURE_GUIDE.md for scope.
